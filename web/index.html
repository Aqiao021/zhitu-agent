    职途助手是怎么工作的

    1. 岗位库

    岗位库收录 14 个热门高职专业的典型岗位画像。每个岗位的要求由职途助手根据高职院校公开的 2025 级人才培养方案和 2025—2026 年公开招聘信息归纳整理，并附上来源链接；它们不是某家公司的真实招聘。同学提交的真实招聘信息会先隐藏个人信息，经管理员整理审核后入库，并标注“真实招聘”。证书名称和职业代码以官方最新发布为准。

    2. 诊断流程

    系统先在本地隐藏简历中的个人信息，再把简历和招聘信息交给大模型，让它拆解岗位要求、判断状态并引用简历原文。返回结果后，程序逐字核验每一条引用：原文在简历中找不到，就把该条从“具备”降为“部分具备”，并在页面上说明原因。匹配度由程序按统一规则计算（必需项权重为 2，加分项为 1）。

    3. 30 天计划

    大模型只负责设计学习模块（每个模块对应一项差距，写明要学会的软件和按顺序执行的小任务）；排期由程序完成：第 7、14、21、28 天复盘，第 26、27、29 天做综合项目，第 30 天更新简历并模拟面试，其余是学习日，每天的任务总时长不超过你设定的时间。

    4. 资料库

    就业问答使用本地资料库检索（SQLite 全文索引），只把检索到的片段交给模型，并要求逐句标注编号；程序会删除不存在的引用编号。资料库中的每份文件都写明发布单位、日期和原文链接。

    就业问答在浏览器里检索公开资料，只把相关片段发给所选模型，并要求逐句标注编号；程序会删除不存在的引用编号。每份资料都列出发布单位、日期和原文链接。

    5. 使用自己的 API Key

    你可以在右上角填写自己的大模型 API Key（支持 DeepSeek、通义千问、智谱、Kimi 等）。Key 默认只保存在当前浏览器标签页，勾选“记住”才会保存在这台设备上；每次请求时随请求发送到职途助手服务器，只用来调用你选择的服务商，服务器不保存、不记录。费用由你的账户承担，建议在服务商后台设置额度上限。为防止服务器被滥用，只能选择列表中的服务商地址。

    点击右上角的模型状态填写自己的 API Key。Key 只在当前页面内存中使用，刷新或离开页面后清除，不写入浏览器存储。请求直接发往设置中的 HTTPS 模型接口，费用由你的模型账户承担。连接能否成功也取决于服务商是否允许浏览器跨域访问。

    6. 隐私

    手机号、身份证号、邮箱、QQ/微信号、住址在发送前被替换为“[已隐藏]”。服务器不保存简历和招聘信息原文，只记录功能使用次数、耗时和你主动提交的评分，用于改进工具。

    手机号、身份证号、邮箱、QQ/微信号、住址在发送前会被遮盖。诊断结果（含遮盖后的引用）、计划、进度和使用记录保存在本机浏览器，不汇总其他访客的数据。可在「本机记录」页导出或清除；换设备或清除浏览器数据后无法查看。

    7. 诚信

    职途助手只帮你找差距、做计划、练表达，不会帮你编造经历、夸大成果或伪造证书。如果发现简历中的表述无法证实，会提醒你如实修改。

    8. 局限

    诊断质量取决于所接入的大模型和招聘信息的完整程度，结果仅供参考。政策和学校信息请以官方最新发布为准，求职决定建议结合就业指导老师的意见。
